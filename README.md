# rpg

A silly little RPG. Walk around and talk to NPCs, find the shop and crack the code to get a special card, battle Rebeka and Flicker, and move a few boxes around!

## Controls

- WASD to move
- Q to interact and grab boxes
- Left click to advance dialogue
